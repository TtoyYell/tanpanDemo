# 谈判模拟

这是一个纯前端的文字经营谈判 Demo，不需要安装依赖。

## 运行

直接用浏览器打开 `index.html`，或在当前目录启动一个本地服务器：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 已实现

- 两关：供应商谈判、税务官谈判
- 每关有 2 条公开信息免费获得，现场信息总比行动点多 1 条
- 第一关为 7 条现场信息、6 次行动；第二关为 5 条现场信息、4 次行动
- 谈判前调查、人物/处境/证据/公开信息收集
- 公开信息与现场记录互相冲突时，组合成矛盾筹码
- 谈判第一阶段交流、询问、提出诉求
- 双方提出诉求后进入第二阶段
- 施压、让步与条件交换、结束和中止谈判
- 心情、心理距离、耐心、警觉度与目标达成度反馈
- 目标达成度由条款完成情况计算，全部达到目标时为 100%
- 心情影响询问；降低诉求恢复心情，提高诉求降低心情
- “让步与交换”共用一个入口：单方让步不会随机失败，互换条件受心理距离影响
- 综合状态过低时相关操作可能失败；施压失败会同时降低心情、距离和耐心
- 交流与询问在第二阶段继续可用；交流效果会结合当前状态判断
- 第二关只有蓝莓茶、旧税戳和封路公告是强关系恢复；季度表与复核顺序为条件弱效果，受当前心情、距离、耐心和警觉度影响
- A-F 评级同时考虑目标达成度、综合状态、失败次数与后续风险
- 条款标明“越低/越高更好”，并实时显示“已满足/未达成”
- 第一关围绕合同总价、持续供货周期和每批供货量谈判
- 分阶段条款和最终评级结算
